## The Idea

A Google Maps-style interactive map of the Game of Thrones known world — the kind where you can pan across Westeros, zoom into King's Landing, and eventually plan a journey from Winterfell to Dragonstone and get told how long it takes on horseback.

Inspired by the *Atlas of Ice and Fire* maps and the [Quartermaester](https://quartermaester.info) interactive map. Built as a personal technical challenge: real map infrastructure applied to a fictional world.

## What's Built

**Tile-based map rendering** — The source is a 9050×6000px reference map sliced into a 7-level tile pyramid (zoom 0–6) using a custom Python/Pillow script. 256×256 JPEG tiles served statically. The tile pipeline is the same architecture used in production web mapping systems.

**Leaflet with CRS.Simple** — Because the world isn't round, the map uses Leaflet's `CRS.Simple` coordinate system (pixel coordinates on the image, not lat/lng). The map is bounded so you can't pan off the edge of the known world.

**Next.js 15** — Client-only map component (`"use client"`) with proper cleanup on unmount, housed in a full-screen dark-themed layout.

## What's Planned

The map viewer is the foundation. The destination is a travel planner:

- **Location markers** — 20–30 key locations (Winterfell, King's Landing, Braavos, etc.) plotted from a `locations.json` file using pixel coordinates on the source image
- **Travel graph** — ~40–60 edges connecting locations with distance, terrain type, and allowed travel modes stored in `edges.json`
- **Three travel modes:**
  - *Walk* — Dijkstra shortest path, terrain speed modifiers
  - *Horse* — same graph, faster base speed
  - *Dragon* — straight line, ignores terrain entirely
- **Side panel UI** — origin/destination/mode selectors, result card showing distance and estimated days, route line drawn on the map

## Tech Stack

Next.js 15, React 19, TypeScript, Leaflet (CRS.Simple), Python + Pillow (tile generation)
